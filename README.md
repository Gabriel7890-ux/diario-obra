# Diário de Obra ECTAS

App para o encarregado registrar o RDO no celular, com fotos e legendas, e enviar ao grupo da obra no WhatsApp em PDF, Word ou fotos com texto.

Abra pelo link do GitHub Pages no celular e toque em **Instalar** (Android) ou **Compartilhar > Adicionar à Tela de Início** (iPhone).

Os registros ficam salvos só no celular de quem usa. Nenhum RDO ou foto fica neste repositório.
